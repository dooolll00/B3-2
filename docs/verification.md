```bash
python -m unittest discover -s tests -v
```

- 자동 테스트 25개 통과. 임시 저장소는 테스트 종료 시 제거합니다.
- API 요청은 unittest.mock으로 교체했으며 실제 OpenAI 호출은 0회입니다.
- 파일명 변경 테스트는 처음에 내용 변경까지 기대해 실패했습니다. 내용 변경 없는 rename의 정상 Git diff 형태에 맞춰 기대값을 수정한 뒤 통과했습니다.
- 생성 결과의 형식 검증은 사실 정확성이나 보안 완전성을 보장하지 않습니다.
