**전체 미션 완료 상태가 아닙니다.** 실제 API 응답과 GitHub 업로드는 테스트 대역으로 대체할 수 없습니다.

## 실행한 검증

```bash
/usr/local/bin/python3.12 -m unittest discover -s tests -v
```

- 자동 테스트 22개 통과. 임시 저장소는 테스트 종료 시 제거합니다.
- API 요청은 unittest.mock으로 교체했으며 실제 OpenAI 호출은 0회입니다.
- 파일명 변경 테스트는 처음에 내용 변경까지 기대해 실패했습니다. 내용 변경 없는 rename의 정상 Git diff 형태에 맞춰 기대값을 수정한 뒤 통과했습니다.
- 생성 결과의 형식 검증은 사실 정확성이나 보안 완전성을 보장하지 않습니다.

## 실제 검증 순서

1. Python 3.10+ 가상환경을 활성화합니다.
2. 필요한 새 파일을 스테이징하고 `python main.py all --preview`로 전송 범위를 확인합니다.
3. 같은 셸에서 API 키를 환경변수로 설정합니다. 키는 문서·이미지에 남기지 않습니다.
4. `python main.py all --max-tokens 2500`을 실행합니다.
5. 변경 요약·커밋 제목/본문·PR 3개 섹션과 호출 횟수를 확인합니다.
6. 실제 결과만 날짜·모델·명령과 함께 보관하고 README 예시와 구분합니다.
7. 사용자가 만든 GitHub 저장소 주소를 등록하고 커밋·브랜치 작업 및 push 후 원격 반영을 확인합니다.
